# Cappadocia Turkish Cuisine

1. ZIP içindeki dosyaları GitHub reposunun **ana dizinine** yükle.
2. **Settings → Pages → Deploy from a branch → main → /(root)** seç. Custom domain: `cappadociaturkishcuisine.id`.
3. Menü PDF dosyanı `menu/menu.pdf` olarak yükle. Menü butonu kendiliğinden PDF’ye geçer.

Google yorumları ve fotoğraflarını doğrudan göstermek için `config.js` dosyasına bu Bintaro restoranının **Google Place ID** değerini ve kısıtlanmış **Maps JavaScript API** anahtarını ekle. Google Cloud’da faturalandırma ve Places erişimi gerekir. Anahtarı yalnızca kendi alan adında ve ilgili API’lerde kullanılabilecek şekilde kısıtla. Bu bilgiler yokken gerçek yorum ve fotoğraflar Google Maps bağlantılarından açılır.
